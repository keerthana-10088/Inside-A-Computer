# Inside a Computer - Notes

## 1. Introduction

A computer is an electronic device that receives input, processes data, stores information, and produces output.

## 2. CPU

The Central Processing Unit (CPU) is responsible for executing instructions and processing data.

The CPU performs calculations and controls many operations of the computer.

## 3. RAM

RAM (Random Access Memory) is temporary memory used by the computer to store data and programs that are currently being used.

RAM is volatile, which means its contents are lost when the computer is turned off.

## 4. Storage

Storage devices are used to permanently store data and files.

Examples:
- Hard Disk Drive (HDD)
- Solid State Drive (SSD)

## 5. Operating System

An operating system manages computer hardware and provides an environment for applications to run.

Examples:
- Windows
- Linux
- macOS

## 6. Input and Output

Input devices allow users to provide information to a computer.

Examples:
- Keyboard
- Mouse

Output devices provide information from the computer to the user.

Examples:
- Monitor
- Speakers
